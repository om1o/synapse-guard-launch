Privacy · October 11, 2026

Your draft.
In your browser.

The public browser demo runs the checker locally. Its checker code makes no network request containing your draft, evidence, findings, or report.

Browser memory

Drafts and supplied evidence live in the page's memory. The demo does not write them to localStorage, cookies, a database, or a source provider. Spellcheck is disabled by default. Reloading or closing the page clears the application's in-memory values. Your browser, extensions, keyboard tools, or device may independently process text or provide recovery and history features.

Hosting and third-party links

Cloudflare serves the website and may process ordinary request metadata such as IP address, request path, and user agent. There are no advertising pixels or third-party analytics scripts in this demo. Opening a cited source link visits that provider. GitHub hosts public community posts under its own policies.

Feedback and pilot requests

Public GitHub submissions can contain the profile identity and information you deliberately submit. Keep drafts, source records, personal contact information, and credentials out of public issues. If you mistakenly share sensitive content, use the private security reporting route to request removal, referencing only the issue number. Do not repost the sensitive content. Third-party copies may still exist.

Private staging is separate

The authenticated staging service can store optional account-scoped evidence snapshots, but does not persist draft bodies. Seven-day exclusion from checks is not physical deletion. Deleting a staging account's sources removes current configuration, snapshots, and sync-attempt records from the active database; Cloudflare D1 backup history may retain restorable state for 7 days on Free or 30 days on Paid. Private staging is not the public browser demo.

Human review

Synapse Guard reports supported possible conflicts, not a guarantee of factual accuracy or permission to send. You remain responsible for the message, source access, and final decision. Do not use the demo as the sole basis for consequential decisions.
