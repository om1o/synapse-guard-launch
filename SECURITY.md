# Private security and sensitive-data reports

Use [GitHub's private security reporting route](https://github.com/om1o/synapse-guard-launch/security/advisories/new) for a suspected security problem or accidental sensitive disclosure in a public issue.

For removal requests, include only the issue number and the type of information that needs removal. Do not copy the sensitive content into a second report. Public comments and copies held by third parties may remain outside our control.

Ordinary product feedback belongs in the public issue templates and must use synthetic or redacted examples.
